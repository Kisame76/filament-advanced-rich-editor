# art

Images the README and the plugin directory use.

- `editor.png` — the screenshot at the top of the README. One frame showing the toolbar with
  a dropdown open, a divider, a heading, a task list with one box ticked, and a captioned
  image. Light theme, because it reads better at thumbnail size.

The README links it as `art/editor.png`. Until the file exists the image line renders as
nothing, which is why the README is safe to publish before the screenshot is taken.
